# Flight tracker demo

Standalone adaptation of the owner's India + USA flight-tracker prototype.

All 12 aircraft records, positions, routes, speeds and altitudes are fictional demonstration fixtures. This is **not live flight tracking** and must not be used for travel or operational decisions.

- Static HTML/CSS/JavaScript: no build step or backend.
- India / USA regional browsing, identifier & route search, aircraft details, map markers and browser-local saved samples.
- Leaflet 1.9.4 from unpkg; OpenStreetMap tiles with visible attribution.
- No Wabi credentials, private account data or conversation content included.
- Serve `index.html` from any static web server. GitHub Pages can serve the repository root on `main`.

Favorites are local to the viewer's browser and do not sync with Wabi or other devices.
